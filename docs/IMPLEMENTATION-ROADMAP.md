# Implementation Roadmap

## Phase 0 — Foundation
- Finalize product scope, visual direction and scene map.
- Create Next.js + TypeScript application skeleton.
- Add linting, formatting, type-checking and basic tests.
- Create Supabase project and reviewed migration workflow.

## Phase 1 — First playable world
- Build responsive shell and Festival Home.
- Load one optimized main 3D scene.
- Add avatar setup, movement and graphics presets.
- Add guest entry and account profile persistence.

## Phase 2 — Core festival activities
- Build Krathong Creator and save/load design.
- Add Floating Ceremony and wishes.
- Add camera/photo mode with local capture.
- Add album and explicit optional upload.

## Phase 3 — Friends and rooms
- Add room create/join and invitation links/codes.
- Add realtime presence and avatar movement.
- Add reconnect, room capacity, kick, block and report flows.

## Phase 4 — World expansion
- Add Golden Temple, Moon Bridge, Lotus Garden, Starry Sky and Floating Market.
- Add festival fair, themes, emotes and shows.
- Add missions, achievements and inventory.

## Phase 5 — Hardening and launch
- Performance testing on mid-range mobile devices.
- Accessibility, privacy, security and abuse testing.
- RLS/Storage policy audit.
- Backups, monitoring, quotas and deployment runbook.
- Soft launch and feedback cycle.

## Definition of done
A feature is complete when its loading, empty, success, error and permission states are designed; it works on mobile and desktop; authorization is enforced server-side; and automated or manual tests cover the critical path.
