## Suggested navigation model
- On desktop, use a compact left rail or top navigation plus a persistent avatar/profile entry.
- On mobile, use a bottom navigation for the most frequent destinations and an expandable More menu.
- Keep scene-specific actions close to the 3D viewport; avoid covering the main view with large panels.
- Provide a clear Home/World return action from every secondary screen.

## Main user journey
Home -> Enter World -> Avatar Setup -> Explore -> Create Krathong -> Invite Friends -> Ceremony -> Photo/Album -> Achievements.

## Room joining
Invite link or code -> Preview room -> Confirm display name/avatar -> Join -> Show room members -> Return to world or leave room.
